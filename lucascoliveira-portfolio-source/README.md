# Lucas Oliveira — Engineering Portfolio

Static source code for `lucascoliveira.com.br`.

## Structure

- `dist/index.html` — page content and semantic structure
- `dist/styles.css` — responsive design, theme and animations
- `dist/script.js` — reveal animations and dynamic year
- `dist/lucas-oliveira.webp` — optimized profile photo
- `dist/favicon.svg` — website icon

## Run locally

    python3 -m http.server 8080 --directory dist

Then open `http://localhost:8080`.

## Deployment

The `dist` directory can be published on GitHub Pages, Cloudflare Pages, Netlify, Vercel or another static host.
